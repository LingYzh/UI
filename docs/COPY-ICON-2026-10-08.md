# 复制按钮图标修复

## 需求与实现

用户反馈行内复制按钮只有底色，没有图标。盘点复用 UiCopyButton、UiButton、Icon 和现有 `copy-button` 文档页，不新增组件或公开属性。

UiButton 内容现已包裹在 `.ui-button-content` 内，旧 `.ui-copy-button > svg` 尺寸和动画规则无法匹配实际图标。root 将复制/成功状态改为已登记的 `mdi-content-copy` / `mdi-check`，使用 Icon 固定 15px 大小和专用 `.ui-copy-button-icon` 动画类，避免依赖按钮的直接子元素结构。状态切换重新播放短动画，系统或主题减少动效设置继续关闭动画。

保留完整原文复制、固定按钮名称、成功 status 播报、绿色反馈和 1.6 秒自动恢复。已有真实 demo 继续覆盖 Access Token 与邮箱，API 不变；无需修改源码示例或调用方。
