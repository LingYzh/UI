# 表单行为补全与验收计划

## 组件盘点

- Input/Select/Textarea 已有 width/minWidth/maxWidth，缺口是 Select 的 selectedcontent 不换行／省略与 picker 内容宽度；Input 保留原生单行滚动选择，Textarea 保留多行编辑。
- Tooltip 已支持 hover/focus，但 focusin 未区分指针与键盘，点击后残留展示。
- Dialog error 当前是 flex 子项，会缩短滚动 viewport；改为正文外壳内 absolute 悬浮，正文 padding 按错误实测高度预留，不改变 viewport 高度。
- UiForm 目前只有布局与 reportValidity，需要注册所有库输入控件、同步／异步 rules、三态 v-model、validate/reset/resetValidation、validateOn、错误汇总与全表单状态／外观继承。

## 已定契约

- 扩展 UiForm，不建立平行表单组件。validate() 返回 Promise<{ valid, errors, cancelled? }>，保留 submit 的 SubmitEvent 参数（只在验证通过时发出），增加 invalid 事件；reset() 恢复挂载初始值，resetValidation() 保留数据并清除校验。
- Input/Select/Textarea/Switch/Checkbox/Radio/ColorSwatches 支持 rules、errorMessages、validateOn；UiField 自动关联子控件错误。规则 true 为通过，false 使用通用错误，string 为错误文字，支持 Promise。原生 required/min/max/type/maxlength 继续参与验证。
- validateOn input/blur/submit，默认 input；字段可覆盖 Form。异步规则按值与代次判断，过期结果不能覆盖新值、reset 或卸载；提交期间重复提交锁定。
- Form 统一 disabled/readonly/dense/ghost/rounded；控件外观可显式覆盖，Form disabled/readonly 强制约束。readonly 的选择类不可改变，文本仍能聚焦与选择。
- 选择按钮单行 ellipsis，下拉 option 主标签单行，描述允许换行；picker 最小为触发器宽，最大为视口，按内容增长。Input text-overflow=clip，容器 overflow=hidden，保持原生选择及 scrollLeft。
- Tooltip 保留 hover，指针点击产生的 focus 不参与显示；指针移出关闭，Tab 后保持，Esc/滚动关闭。
- Demo 必须覆盖三种菜单宽度、长输入编辑、键盘 Tooltip、动态多行错误浮层、同步／异步表单验证、状态／外观继承、reset 与过期校验；取消和生命周期失效由 runner 测试覆盖。

所有产品样式与 demo 由 root 编写，测试可委派经济型代理；库内验收后才考虑发布和 UAH 消费升级。

## 控件内置标签与简化 API

所有输入控件内置 label、hint、labelPosition=top/left、labelWidth、rules 和验证信息。UiForm 统一设置，子控件可覆盖方向与外观；只读和禁用不可解除。标准用法直接 Form → 控件，UiField 仅用于自定义项目。说明与错误放在控件下方，不为缺失说明预留空白。Tooltip 保留真实 hover 提示，指针点击后的 focus 不参与显示；移出关闭，Tab 保持。

## 本轮职责收敛
复用 UiRow/UiCol 的行列、断点与间距能力。UiForm 只管理验证、提交、重置和共享控件状态/外观，移除 layout/columns/density/actions。UiFormSection 只作 fieldset/legend 分组，移除 columns；控件/Field 移除 span，整行通过 UiCol cols=12 表达。全部真实示例和 API 参考同步；Row/Col 新增表单案例。

## 级联选择器缺口
新增 UiCascader。复用 ControlSizing、内置 label/hint、FormControlProps 与验证注册，使用原生 Popover 避免弹窗裁剪。items 为 {value,label,disabled?,children?}[]，v-model 为值路径数组，默认只选叶节点，可 changeOnSelect 选父节点。默认全路径显示；支持 clearable、showAllLevels、separator、placeholder，键盘上下/Home/End 同级移动、左右逐级导航、Enter/Space 选择、Escape/Tab 关闭，指针选中释放焦点而键盘返回触发器。对应独立文档和 Row/Col 表单案例。
