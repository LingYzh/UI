# @lingyzh/ui 0.6.2

校准 Anthropic / Claude 陶土品牌色，统一组件、真实示例和文档外壳的颜色角色，保留现有公开属性及业务状态色。

## 变化

- 浅色强调文字与填充均使用 `#d97757`；深色强调文字为 `#e6a086`，选中背景为低强度陶土色。默认品牌实心表面及加载图标保持白色前景，其他自定义色自动选择前景，显式 `on-*` 优先。
- 统一语义颜色与原始 CSS 色值的解析，覆盖按钮、选择控件、工具栏、Snackbar、面板、picker/field、标签/徽标/头像、Tooltip、快捷键、时间轴与图片占位；避免父级颜色变量污染子组件。
- 静态 CSS 与主题服务的文字、背景和边框工具类对齐；页签指示线使用填充色，彩色工具栏内保持可辨识的指示线。
- demo 品牌、导航、链接、眉题、页签和目录跟随同一主题；移除额外导航左色条。新增真实主题组合及完整可复制源码，接入文档生成流程。
- 修复新文档模块的 Node ESM 扩展名；旧按钮专项改用真实只选交互和关联列表，Electron 颜色专项固定设备缩放比例以避免 Windows 像素取整误报。
