# Tabs 使用和行为对齐

盘点：已有 UiTabs 依赖 items/idPrefix/string v-model，UiTabTrigger 仅内部使用；UiTabPanel 逐项绑定模型。方向键自动激活，没有声明式 Tab、统一 Window、数字／索引值、布局伸展和滚动箭头。

复用 @vuetify/v0 Tabs 的注册、禁用、选择与键盘行为，保留 UAH tokens、slider、ripple、pointer blur。增加 UiTab、UiTabsWindow、UiTabsWindowItem；Tabs 使用声明式 default 或 items 数据，模型与 idPrefix 可选。默认 mandatory=force、activation=manual；方向键／Home／End 移动焦点，Enter／Space 选择；automatic 可显式启用。值为 string/number，未声明 value 使用项索引，数字 0 保留。旧 id/label 数组、orientation 与 UiTabPanel 继续兼容，现代 items 使用 value/text 和 #tab/#item。

TabsWindow 统一控制内容；与 Tabs 相邻时共享 v-model，#window 内可自动继承模型／关联 IDs，不要求逐项重复绑定。WindowItem 默认首次访问挂载并保留状态，eager 可预先挂载。UiTabPanel 仍保留旧的完整挂载语义。

布局补充 direction、alignTabs、grow、fixedTabs、stacked、hideSlider、centerActive、showArrows；保持单行、不挤宽页面，滚动只发生在标签列表，选中项与键盘焦点在视口内。默认手动确认的行为同步所有 demo 和文档测试；新增组件必须独立文档和真实 demo。API 审计更新覆盖新增组件。

参考官方 VTabs / VTab / VTabsWindow / VWindowItem 源码与 tabs/usage.vue。root 负责实现、视觉和最终验收；辅助 API 核对及专项测试可委派。验收覆盖声明式／数组、数字与默认值、禁用、动态删除、空列表、嵌套上下文、面板懒挂载／状态、键盘手动与自动激活、滚动边界／布局、浅深窄屏及125%。

## 激活项 hover 增量

复用 UiTabs/UiTab、现有声明式／数组／变体真实 demo 和 docs ExampleCard，无新组件或 API。普通 hover 选择器比 aria-selected 激活态具有更高优先级，导致激活背景／文字被覆盖；文档示例标签的额外选中规则掩盖了问题。限制 hover 为未激活且非禁用的项，保留激活态及 ghost 的既定样式；删除文档重复选中覆盖，统一复用库规则。root 验收浅深、横纵、常规／紧凑／ghost／square 的选中 hover、未选中 hover、禁用项及示例／源码切换。
