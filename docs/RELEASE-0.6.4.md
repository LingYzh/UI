# UI 0.6.4

## 本次变化

- 表格默认加载条复用 UProgressLinear，保留普通/服务端/虚拟/树表的颜色、位置、3px高度、插槽与busy语义，修正独立缩放动画与线性进度不一致。
- 实心组件使用统一白字优先策略，线性相对亮度达到0.7才自动用黑字；浅蓝、浅绿、浅灰保留白字，近白与浅黄用黑字。显式on-*与正文主题保持优先，静态CSS同步。
- 前景解析兼容不存在CSS对象的非浏览器环境。真实主题/表格demo、可复制源码、API说明和回归检查同步。
