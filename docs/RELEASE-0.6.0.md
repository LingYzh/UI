# @lingyzh/ui 0.6.0

本版本汇总 NC_Admin 迁移期间补齐的组件与交互，不表示已实现全部 Vuetify 属性或完成消费端真实后端验收。

## 主要变化

- 新增通用详情抽屉、树形表格、时间输入及日期模式支持；保留已有公开组件入口。
- 树选择支持多选和独立勾选。`multiple` 模式使用数组模型，默认选择策略为 `independent`，选择后保持展开，清空为 `[]`；单选行为保持兼容。
- 补齐级联多选、输入框搜索、树内拖拽和表单设计器所需的控件预览能力。
- 修复固定列边界、表头背景缝隙、密度继承、按钮文字与图标对齐、加载动画及多选长文本布局。
- 完善弹层进出、选择器重复点击收起、日期时间紧凑编辑、滑块重合操作及快捷操作展开交互。
- 只读表单继续执行校验；只读状态变化不会清除在途校验与错误。业务端应在校验时只读、写入时禁用。

## 消费约定

- 包继续发布 Vue/TypeScript 源码，消费端需要 TypeScript 供 Vue SFC 编译器解析类型。
- 使用本地源码链接的应用需要去重 Vue；本轮 NC_Admin 继续使用 `link:../UI`，不随发版改成远程包。
- 生成与导出代码模板、真实后端权限和文件生成不属于本次库发布的验证范围。

## 验证

发布门禁与证据记录在 `VALIDATION.md` 和 `HANDOFF.md`。版本是否已发布以 Git 标签、GitHub Actions 和官方 npm registry 的最终记录为准。
